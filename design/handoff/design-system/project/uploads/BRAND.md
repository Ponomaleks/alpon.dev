# alpon.dev · Fjord

Фірмовий стиль Alexander Ponomarenko. Починався з візитки, далі йде на сайт alpon.dev, шапку LinkedIn та інші матеріали.

## Ідея

Нордичний мінімалізм: світлий кам'яний фон, глибокий хвойно-зелений і топографічні горизонталі. Горизонталі нагадують карту Nordmarka і водночас ізолінії на графіку. Креатив тихий: одна виразна деталь, решта спокійна.

## Кольори

| Токен | HEX | CMYK (друк) | Для чого |
|---|---|---|---|
| stone | `#F3F4F0` | 3 / 1 / 5 / 2 | Світлий фон, лицьова сторона |
| spruce | `#24493D` | 82 / 45 / 70 / 45 | Темний фон, зворот |
| accent | `#2E5E4E` | 80 / 40 / 65 / 28 | Акцентний текст, посилання, фокус |
| ink | `#1B2421` | 0 / 0 / 0 / 100 | Основний текст, QR |
| muted | `#5E6B65` | 40 / 20 / 35 / 50 | Другорядний текст |
| snow | `#EEF2EE` | 3 / 0 / 4 / 0 | Текст на spruce |
| lichen | `#BFD3C9` | 25 / 5 / 20 / 0 | Другорядний текст на spruce |
| contour | `#9CC3B2` @ 28% | 72 / 38 / 60 / 22 (flattened) | Горизонталі на spruce |

Правила:

- Один темний колір на композицію: або spruce як фон, або ink як текст на stone.
- accent лише для акцентного тексту та інтерактиву, не для великих заливок.
- У друці дрібний текст і QR тільки в K 100, щоб не було проблем з приводкою.

## Шрифти

- **Schibsted Grotesk** 400 / 500 / 600 / 700: заголовки, ім'я, основний текст. Гротеск, створений для норвезької медіагрупи Schibsted.
- **JetBrains Mono** 400 / 500: контакти, URL, технічні підписи. Акцент розробника.
- Максимум дві гарнітури. Заголовки з tracking -0.01em.
- Обидва шрифти під ліцензією OFL: можна використовувати на сайті й у друці безкоштовно. TTF лежать у `fonts/`, для сайту простіше підключити Google Fonts (див. `tokens.css`).

## Графічні елементи

- **Горизонталі** (`patterns/`): безшовна плитка 600 × 600, повторюється в обидва боки на будь-якій площі. Лінії 13% на stone або 28% на spruce. На картці горизонталі виходять з кута, на вебі плитка заливає цілі секції.
  - Фон з кольором: `background: url(pattern-contours-tile-spruce.svg) repeat; background-size: 600px;`
  - Під будь-яку тему: `pattern-contours-tile-mask.svg` як `mask-image`, колір задається через `background-color` (напр. `var(--fjord-contour)` з opacity .28).
  - Щоб повтор був менш помітним, збільшуй `background-size` (900-1200px).
- **QR** (`qr/`): круглі точки 0.62 модуля, заокруглені фіндер-патерни, рівень корекції Q, веде на https://alpon.dev. На темному фоні завжди на світлій плашці stone з радіусом ~6% ширини.
- **Сітка**: поля 6 мм на картці. На вебі базовий крок 4 px, вирівнювання по лівому краю, асиметрія.

## Файли

- `tokens.css` / `tokens.json`: кольори, шрифти, відступи, параметри картки.
- `fonts/`: статичні TTF + ліцензії OFL.
- `qr/`: QR у SVG (ink, spruce, ink на stone) і PNG 1240 px.
- `patterns/`: безшовні плитки горизонталей (spruce, stone, прозорі, маска).
- `card/`: SVG обох сторін з вильотом і PNG 2000 px в обрізному форматі для вебу й соцмереж.
