Lucide-derived line icon at 1.5px stroke; use for UI affordances only, never as decoration or emoji substitutes.

```jsx
<Icon name="arrow-right" size={20} />
```

`name` is a Lucide id copied into iconData.js (arrow-right, arrow-up-right, copy, check, mail, phone, download, file-down, sun, moon, search, menu, x, map-pin, chevron-*, …). Pass `label` only when the icon stands alone and carries meaning.
