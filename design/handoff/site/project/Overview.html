Every frame below is the live prototype (alpon.dev.html) at that width, so it can be scrolled and clicked. Open the prototype for the full flow; Tweaks toggle the portrait, recommendations, catalog size and form result.

Copy follows the Fjord guide where it differs from the brief: buttons say “Get in touch” (not “Ta kontakt”), theme labels are Light / Dark, toast says “Copied”. Norwegian stays in small details (Hei, Oslo, Norge, Nå, Skann meg, Ikke funnet) and the NO CV. To switch the CTA to “Ta kontakt”, Header and MobileMenu need a ctaLabel prop.

New components

Built from Fjord tokens and primitives, in site/ext.jsx + site/site.css. Candidates to move into the design system.

ComponentWhat it is
QuickFactsMono key / value list (Based in, Focus, Languages). Hairline rows, 96px key column.

Natt spruceToken extension: in Natt, .fjord-on-spruce maps its ground to spruce-deep #1A362D (CTA band, menu sheet). Heroes switch to the night ground with contour-line contours and auto terrain, so the first screen changes with the theme.
BackToTop44px secondary IconButton with float shadow, bottom-right; above the sticky bar on mobile.
vCard QRQR encodes the contact card. Light uses the transparent ink version, Dark the version on a stone plate.
