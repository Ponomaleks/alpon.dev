### Resolution details

**S1-01 + S2-01 — baselines (Owner decision).**
- Main path: `visual-baselines.yml` also triggers on `pull_request` with types `[labeled, synchronize]`. It runs only when the PR has the `visual-baselines` label, so every new push regenerates the baselines while the label is on.
- The job uploads the PNGs as an artifact. The Owner reviews them against the design, commits them under `tests/visual/__screenshots__/linux/`, then removes the label.
- Fallback, not the main path: document the equivalent local `docker run mcr.microsoft.com/playwright:v1.63.0-noble … FJORD_VISUAL=write` command in the README.
- Once the baselines are committed, the normal `visual` job must pass without `continue-on-error`. T15 then moves to done.

**S1-02 — required checks (Owner decision).**
- Require both `check` and `visual`, and apply this to `v2` now.
- For `main`, record two options; the Owner picks one when running the commands:
  1. Protect it now with admin bypass allowed (`enforce_admins: false`), so a stub hotfix can still merge before Release 1.
  2. Apply the `main` protection as part of the Release 1 step.
- Keep both jobs free of path filters and job-level conditions on PRs into `v2`/`main`. A required check that never reports blocks the merge forever. Today `ci.yml` has neither; add a comment so it stays that way.
- Record the exact `gh api` commands in T16 and in the PR. The Owner runs them.

**S2-02 — CSP audit.** In the script branch, decide only whether the body counts as an inline-script problem, without `continue`. The style and handler checks must run for every element. Add the three probe cases to the F-06 `it.each` in `src/integrations/csp.test.ts`.

**S1-03 + S1-04 — AC-05 tests.**
- Create the contexts from the project's `use` settings, or measure explicitly at 390 and 1440.
- After `document.fonts.ready` on the Not-found page, assert with `platformFonts` that `.code` is drawn in JetBrains Mono and `main p` in Schibsted Grotesk.

**S2-03.** Run the snippet in a `vm.createContext` context, then assert `vm.runInContext('typeof t', ctx) === 'undefined'`. Or run it twice in one context and expect no error.

**S2-04.**
- Add `cqw`, `cqh`, `cqi`, `cqb`, `cqmin` and `cqmax` to the disallowed units.
- Restrict the height properties by value: tokens, `auto`, `%`, and only `100vh`/`100svh`/`100lvh`/`100dvh`.
- Add a fixture line for each case.

**S2-05.**
- Classify each `*-scale` token by how the handoff CSS uses it: `scale(var(--x))` is a factor and resets to 1; `calc(1 + var(--x))` is a delta and resets to 0. Throw if neither is found.
- Throw when a movement token (rise/slide/parallax/scale) is declared outside motion.css.

**S2-06.** In spec §6 and §7, state that SEO is not asserted on the noindex Not-found page, because Lighthouse's crawlability audit fails a noindex page by design. List it among the PR's deviations.
